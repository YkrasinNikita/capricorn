# Документы для поиска

Сюда можно положить свои `.md` и `.txt` файлы — Капри найдёт по ним ответ локально,
без облака. Подпапки тоже читаются.

## Как пользоваться

1. Скопируй сюда 2–3 документа (заметки, инструкции, конспекты).
2. Скажи: «проиндексируй документы» или запусти `python tools/rag_index.py`.
3. Спроси: «найди в документах …» или «что сказано в документах о …».

Ответ прозвучит с названием файла-источника. Заметки из `notes.json` ищутся вместе
с документами и не требуют переиндексации.

Индекс лежит в папке `index/` и в git не попадает. Если модель эмбеддингов
`nomic-embed-text` не скачана, поиск работает по словам:

```
ollama pull nomic-embed-text
```
